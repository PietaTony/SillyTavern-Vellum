Vellum —— 快速開始
==================

1. 先裝 Node.js
   https://nodejs.org  ← 下載 LTS 版（左邊那顆綠色按鈕），需要 20.19 以上。

2. 啟動
   macOS   ：雙擊「啟動.command」
   Windows ：雙擊「啟動.bat」

   第一次在 macOS 上可能會說「無法打開，因為來自未識別的開發者」——
   在那個檔案上按右鍵 → 選「打開」→ 再按一次「打開」，之後就不會再問。

3. 瀏覽器會自動打開 http://127.0.0.1:8520
   沒有自動打開的話，自己在瀏覽器輸入這個網址。

4. app 會帶你走一次：選供應商 → 貼 API 金鑰 → 測試連線 → 加第一個好友。


怎麼停止
--------
關掉那個黑色（或白色）的終端機視窗就是停止。


你的資料在哪
------------
就在這個資料夾底下的 data\ 裡面 —— 角色、對話、世界書、API 金鑰全都在那。

  備份 = 把 data 這個資料夾複製一份。

  更新 = 下載新版 zip 解壓到「新的」資料夾，
         把舊的 data 整個複製過去，再開新資料夾的啟動檔。
         確定沒問題之後才刪掉舊資料夾。


誰連得到
--------
預設「只有這台電腦」連得到。Vellum 沒有登入機制 ——
任何連得到那個網址的人都等於是你，能讀你全部的對話、用你的金鑰花錢。

要讓自己的手機連進來，建議用 Tailscale（把你的裝置組成一個私有網路），
詳見專案 README 的「從手機或平板連進來」。

請不要直接開到公網。
