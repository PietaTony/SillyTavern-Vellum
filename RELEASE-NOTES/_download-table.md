## 要下載哪一個

| 你是 | 下載 | 之後的更新 |
|---|---|---|
| **Windows（建議）** | `Vellum Setup <版本>.exe` —— 雙擊安裝 | ✅ **app 會自己通知你，一鍵更新** |
| Windows（免安裝） | `Vellum <版本>.exe` —— 直接執行 | ❌ 要自己回來下載新版 |
| Mac | `.dmg`（M 系列選 `arm64`，Intel 選另一個） | ✅ app 會自己通知你 |
| 已經有 Node 24 / 想自己跑 | `.zip` —— 解壓後執行 `啟動.command`（Mac）或 `啟動.bat`（Windows） | ❌ 要自己回來下載新版 |

免安裝版沒辦法自動更新 —— 它是一個放在你自己資料夾裡的單一檔案，更新程式沒有地方可以覆寫。

Mac 的 `.dmg` 是 ad-hoc 簽章，第一次開啟要在「系統設定 → 隱私權與安全性」按允許。
