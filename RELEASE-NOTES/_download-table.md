## ⚠️ 目前是 Alpha 版本

功能還在快速增減，畫面與操作方式**可能在版本之間直接改變**，不保證每一版都相容。
重要的對話與角色卡建議自己另外留一份。

## 要下載哪一個

| 你是 | 下載 |
|---|---|
| **Windows** | `Vellum-Setup-<版本>.exe` —— 雙擊安裝 |
| **Mac（M1／M2／M3／M4）** | `Vellum-<版本>-arm64-mac.zip` |
| **Mac（Intel）** | `Vellum-<版本>-intel-mac.zip` |

**三個檔案都會自己通知你有新版，一鍵更新。** 其餘那幾個 `.yml` 是更新程式自己讀的，不用管。

不確定自己的 Mac 是哪一種：左上角  → 「關於這台 Mac」，看「晶片」那一行。
寫 Apple M 開頭的選 `arm64`，寫 Intel 的選另一個。

## Mac：解壓縮之後怎麼打開

🔴 **打開時會跳出一個對話框，寫著「Apple無法驗證……」，有兩顆按鈕——按錯那顆會直接把檔案刪掉、
得重新下載一次（143 MB）。下面第 2 步會講清楚長什麼樣、該按哪一顆。**

🔴 **這段是暫時的。** 公證（Apple 公證服務）上線之後，Mac 就不會再跳這個對話框，
**這一整段會拿掉**——現在會看到，是因為這個 app 目前只有 ad-hoc 簽章、還沒公證
（Peter 已經付費申請 Apple Developer Program，但會籍還沒啟用，公證還沒能用）。

**步驟：**

1. 解壓縮 zip，把裡面的 `Vellum.app` **拖進「應用程式」資料夾**（不要留在下載／解壓縮的資料夾裡直接開）。
   ⚠️ **這不是禮貌建議，是必要步驟**：Mac 對「還沒信任、放在暫存位置」的 app 會做
   **App Translocation**——把它偷偷搬到一個每次開機都不同、你看不到也改不了的唯讀資料夾
   （這台機器實測抓到的實際路徑長這樣：`/private/var/folders/.../AppTranslocation/<一長串亂碼>/d/Vellum.app`，
   不是你解壓縮出來的那個資料夾）。app 在那種地方跑，存檔、找路徑都可能出怪問題，
   而且每次重開都可能是不同路徑。拖進「應用程式」之後才會脫離這個機制。

2. 雙擊打開。Mac 會跳出這個對話框：

   ```
   未打開「Vellum.app」
   Apple無法驗證「Vellum.app」是否為惡意軟體，它可能會損害你的Mac或危害你的隱私權。
           [ 完成 ]        [ 丟到垃圾桶 ]
   ```

   **按「完成」**（不要按「丟到垃圾桶」——那顆會直接把檔案刪掉，得重新下載）。

3. 打開「系統設定」→「隱私權與安全性」。往下捲，會看到一行提到
   「已阻擋「Vellum.app」以保護你的Mac。」，**按旁邊的「強制打開」**。
   ⚠️ 這顆按鈕現在**不叫**「仍要打開」（舊教學常這樣寫，那是舊版 macOS 的文案）——
   這裡的文字是從這台機器目前系統裡實際的在地化資源檔驗出來的，不是照抄舊教學。

4. 可能還會再跳一次確認（有些機器會要求 Touch ID 或密碼），確認後就會正常打開，
   之後雙擊就跟一般 app 一樣，不會再跳這個對話框。
