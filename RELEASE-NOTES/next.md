## 角色卡終於能匯出了

角色卡片頁一直有能力把卡片存回 PNG——後端這個端點本來就是對的、也早就測過，
但畫面上**沒有任何按鈕能按到它**：改完名字、描述、開場白之後，找不到任何路徑
把卡片帶走。現在對話裡點對方頭像打開「角色設定」層，頂欄多了一顆下載鈕，
按下去存回來的 PNG 跟原始卡片逐位元組相同，改過的欄位也真的會反映在裡面。

⚠️ **自己建立的角色沒有這顆按鈕**——它本來就沒有原始 PNG 可以匯出，不是這顆
功能忘了做，這種角色不會顯示這個入口。

## 這一輪用了多少 token，現在看得到了

供應商回應裡的用量數字，以前送到前端就被靜默丟掉。現在輸入框上方會顯示
這一輪的輸入／輸出 token 數。⚠️ **重新整理頁面就沒了**——目前只存在畫面上，
不會寫進對話紀錄，也不會累計成整個對話的總量。⚠️ **「快取命中」只在有值時才
顯示**：沒有這個數字，代表這家供應商根本不回報，不代表「這一輪沒省到快取」。

## 生成卡住的話，不會再無限期空等了

以前如果供應商建立了連線、卻不吐字也不斷線，畫面會永遠停在「正在思考…」，
輸入框也跟著永遠鎖住——使用者只能自己想到要去按停止鈕。現在連續 60 秒沒有
任何新字進來就會判定逾時，跳出提示要你重試一次，而且**已經吐出來的字會保留
下來**（訊息下方標「已中止，未說完」），不是整段丟掉重來。

## 世界書多了「匯入／匯出」，也多了一本你自己的故事書

世界書現在可以直接匯入 ST 匯出的 `.json` 檔（角色頁、對話頁、全域世界書清單都
有這顆按鈕），也可以把手上的世界書匯出成同樣格式的檔案帶走。另外，你自己的
故事書（persona）現在也能綁一本世界書了——以前只有好友的角色卡才能綁。

⚠️ 綁定的是「別人的那一本」而不是拷貝一份：同一本世界書如果也綁在某位好友
身上，在那位好友的頁面改了條目，這裡也會跟著變，不是各自獨立的副本。

## 遠端連線終於能設密碼了

「允許其他裝置連線」這個開關以前完全沒有密碼保護——連得到的人就能讀你全部
對話、用你的 API 金鑰花錢。現在網路設定頁多了「存取密碼」，開放遠端連線前
必須先設定，其他裝置連進來要先輸入密碼才能用；同一頁也補上了登出按鈕。

⚠️ 這道密碼擋的是「隨手連進來」，不是正式的帳號系統：忘記密碼只能刪掉本機的
一個檔案重設，登出也不會讓舊的登入狀態立刻失效，只是讓這台瀏覽器自己忘掉。
真的要跨網路使用，還是建議優先用 Tailscale 這類工具，密碼是多一層，不是取代。

## 生成中可以按「停止」了

以前一旦送出訊息，只能乾等模型把整段回覆吐完。現在生成中對話區左下角會固定
出現一顆「停止」鈕，按下去會真的中止上游連線，已經吐出來的部分會保留（同樣
標成「已中止，未說完」），不會被當成完整回覆送進下一輪。

## 對話頁新增「變數」面板

角色卡片可能會在背後維護一些數值（好感度、面具、安全感之類）。這一版在對話頁
選單多了「變數」——唯讀顯示這張卡目前的變數值，以及卡片本身宣告了哪些變數、
各自是什麼型別。⚠️ **目前只能看，不能在這裡改**——寫入路徑之後才會考慮開放。

## 新增「輸出規則」：自己寫文字取代規則

對話頁選單多了「輸出規則」，可以自己新增文字取代規則（找什麼字、換成什麼、
套在顯示還是送進模型的版本），全域生效、不綁特定角色卡。卡片自己內嵌的規則
會在這些規則之後套用。

## 桌寵可以關掉了

對話頁選單多了「桌寵」開關，關掉之後桌寵真的會從畫面上消失（不是隱藏），
開回來才會再出現。

## 長對話捲動變快了，但要點一下才看得到更舊的內容

很長的對話以前會把所有訊息一次全部畫在畫面上，捲動會愈來愈卡。現在只掛最新
的一段在畫面裡，往上捲到底會出現「顯示更早的訊息」按鈕，點一次載入更早的一批。

## 世界書的字數預算開始生效了（畫面上還看不到）

世界書送進 prompt 時本來就設計了「超過預算就裁切」，但接線漏了一步，
之前不管塞多少條目都不會裁。這一版接上之後才真的會裁。

⚠️ 這是很初步的防線，不是「現在會正確控制用量」：目前的上限是**字數**，
不是 token 數（這個 repo 目前沒有 tokenizer，字數只是粗略的替代），
數字本身也還沒實際量測過夠不夠用；而且有沒有東西被裁只有伺服器紀錄看得到，
畫面上不會顯示任何提示。

## 其他都是內部調整

這一版另外還有幾項只影響我們自己怎麼開發、怎麼把新版本送出去的變動
（例如檔案歸屬檢查、測試流程與發版說明的驗證機制），跟上面列的功能無關，
你不會感覺到任何差別，也不需要做任何事。
